# Глоссарий проекта LiquidPing

Глоссарий определяет термины, используемые в документах проекта ([SRS](srs/srs.md), [SDD](sdd/sdd.md), [ADR](adr/), [модель вариантов использования](uml/use-cases.md)).

| Термин                   | Определение                                                                                                                     | Где используется               |
|--------------------------|---------------------------------------------------------------------------------------------------------------------------------|--------------------------------|
| Узел (хост)              | Доменное имя или IP-адрес устройства, доступность которого проверяет приложение                                                 | SRS, UC-01                     |
| Список узлов             | Набор узлов пользователя, хранящийся в `hosts.json`; при первом запуске содержит 6 узлов по умолчанию                           | SRS 1.2, UC-01                 |
| Проверка (probe)         | Одна попытка связаться с узлом по ICMP, TCP или HTTP(S)                                                                         | SRS, SDD 005                   |
| Цикл проверок            | Проверка всех узлов списка по включённым протоколам за один запуск; цикл считается успешным, если успешна хотя бы одна проверка | UC-03, SDD 007                 |
| Мониторинг               | Непрерывное выполнение циклов проверок с заданным интервалом                                                                    | UC-02                          |
| Интервал мониторинга     | Время между циклами проверок; по умолчанию 5 с, допустимо от 1 до 60 с                                                          | REQ-FUNC-008                   |
| Тайм-аут                 | Максимальное время ожидания ответа на проверку или соединение, после которого результат считается неуспешным                    | SDD 004                        |
| Статус узла              | Итоговая оценка состояния узла: Available, Unstable или Unavailable                                                             | REQ-FUNC-006                   |
| Pending                  | Начальное состояние узла: ожидание завершения первого цикла проверок                                                            | SDD 008                        |
| Available (Доступен)     | Статус узла: отвечает хотя бы одна проверка и потери не превышают 10 %                                                          | REQ-FUNC-006                   |
| Unstable (Нестабильный)  | Статус узла: потери превышают 10 %, но три неудачи подряд не зафиксированы                                                      | REQ-FUNC-006                   |
| Unavailable (Недоступен) | Статус узла: три неуспешных цикла подряд                                                                                        | REQ-FUNC-006                   |
| Packet loss (потери)     | Доля неуспешных циклов в скользящем окне из последних 20 циклов, в процентах                                                    | REQ-FUNC-007                   |
| Задержка (latency)       | Время от отправки проверки до получения ответа, в миллисекундах                                                                 | REQ-FUNC-003                   |
| ICMP                     | Протокол, на котором работает утилита ping; многие сервисы блокируют его                                                        | REQ-FUNC-003                   |
| TCP                      | Протокол транспортного уровня; проверка узла состоит в установке соединения с портом                                            | REQ-FUNC-004                   |
| HTTP(S)                  | Протокол прикладного уровня; проверка узла состоит в запросе страницы и получении кода ответа                                   | REQ-FUNC-005                   |
| IPv4, IPv6               | Версии протокола IP; узлы могут задаваться адресами обеих версий, обнаружение в локальной сети поддерживает только IPv4         | SRS 1.2                        |
| DNS                      | Система преобразования доменных имён в IP-адреса                                                                                | UC-03                          |
| Reverse DNS              | Определение имени хоста по его IP-адресу                                                                                        | UC-06                          |
| Порт                     | Числовой идентификатор сетевой службы на узле (1–65535)                                                                         | UC-05                          |
| Состояние порта          | Результат проверки порта: открыт (соединение установлено), закрыт (отказ в соединении), фильтруется (нет ответа за тайм-аут)    | REQ-FUNC-010                   |
| Сканирование портов      | Проверка набора TCP-портов выбранного узла методом установки соединения (connect-скан)                                          | UC-05                          |
| Подсеть                  | Диапазон IP-адресов, определяемый адресом сетевого адаптера и маской                                                            | UC-06                          |
| Префикс подсети          | Число бит маски подсети (например, /24); допустимы подсети не короче /22, то есть до 1024 адресов                               | REQ-FUNC-021                   |
| Обнаружение хостов       | Поиск доступных устройств в IPv4-подсетях собственных сетевых адаптеров                                                         | UC-06                          |
| ARP-таблица              | Системная таблица соответствия IP-адресов и MAC-адресов устройств локального сегмента сети                                      | ADR-0005                       |
| MAC-адрес                | Физический адрес сетевого интерфейса устройства                                                                                 | UC-06                          |
| OUI                      | Первые 3 байта MAC-адреса, идентифицирующие производителя устройства                                                            | ADR-0006                       |
| Производитель (vendor)   | Название изготовителя устройства, определяемое по OUI из встроенной базы                                                        | SYS-FUNC-015                   |
| «Тихий» хост             | Устройство, которое не отвечает на ICMP, но присутствует в ARP-таблице                                                          | SYS-FUNC-015                   |
| История                  | Значения задержки за сеанс, хранимые в памяти (не более 1000 точек на узел) и показываемые на графике                           | REQ-FUNC-014                   |
| Трафик проверок          | Объём данных, отправленных и полученных самими проверками за сеанс                                                              | REQ-FUNC-015                   |
| Liquid glass             | Стиль интерфейса: полупрозрачные скруглённые панели с размытием фона                                                            | REQ-INT-001                    |
| Backdrop                 | Системный фон окна (Mica, Acrylic), который рисует Windows                                                                      | ADR-0002                       |
| Тема оформления          | Набор цветов интерфейса: светлая, тёмная или системная                                                                          | REQ-INT-002                    |
| Системный трей           | Область уведомлений панели задач Windows, в которой приложение может оставаться запущенным                                      | UC-11                          |
| Актёр                    | Роль внешнего лица или системы, взаимодействующей с LiquidPing                                                                  | Модель вариантов использования |
| Прецедент (use case)     | Последовательность действий системы, дающая актёру наблюдаемый результат                                                        | Модель вариантов использования |
| Поток событий            | Пошаговое описание прецедента: основной, альтернативные потоки и потоки ошибок                                                  | docs/uml/use-cases.md          |
| REQ                      | Идентификатор требования SRS вида `REQ-[AREA]-[NNN]`                                                                            | SRS                            |
| SYS                      | Идентификатор системного требования SDD вида `SYS-FUNC-NNN` или `SYS-NFR-NNN`                                                   | SDD 5.2                        |
| UC                       | Идентификатор прецедента вида `UC-NN`                                                                                           | docs/uml/use-cases.md          |
