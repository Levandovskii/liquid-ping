# Дополнительные спецификации LiquidPing

Документ содержит требования и ограничения, которые не выражаются отдельными прецедентами: качество, ограничения проектирования, интерфейсы, лицензирование. Источники: [SRS](srs/srs.md), [SDD](sdd/sdd.md), [ADR](adr/). Идентификаторы прецедентов — в [модели вариантов использования](uml/use-cases.md), термины — в [глоссарии](glossary.md).

## 1. Функциональность (общая)

| ID      | Требование                                                                                                             | Источник                 | Прецеденты                 |
|---------|------------------------------------------------------------------------------------------------------------------------|--------------------------|----------------------------|
| SUP-001 | Система ведёт журнал событий и ошибок в `%AppData%\LiquidPing\logs` с ротацией; суммарный размер не более 20 МБ        | REQ-OBS-001, SYS-NFR-009 | UC-03, UC-05, UC-06        |
| SUP-002 | Сетевые ошибки (тайм-аут, ошибка DNS, отказ соединения) показываются с причиной и не приводят к аварийному завершению  | REQ-REL-001, SYS-NFR-007 | UC-03, UC-05               |
| SUP-003 | Система работает без прав администратора                                                                               | REQ-SEC-001, SYS-NFR-005 | все                        |
| SUP-004 | Сканирование портов и обнаружение хостов выполняются только по явному действию пользователя                            | REQ-SEC-002              | UC-05, UC-06               |
| SUP-005 | Система не собирает и не отправляет телеметрию; сетевые обращения только к узлам пользователя и подсетям его адаптеров | REQ-SEC-003              | все                        |
| SUP-006 | Все вводимые данные проверяются, недопустимые отклоняются с сообщением                                                 | REQ-SEC-004, SYS-NFR-006 | UC-01, UC-05, UC-08, UC-12 |
