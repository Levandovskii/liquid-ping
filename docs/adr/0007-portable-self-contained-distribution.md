# ADR-0007: Формат поставки — переносимый self-contained архив для win-x64

## Контекст и постановка задачи

Приложение распространяется как открытое ПО через GitHub и рассчитано на любого пользователя (SRS 1.2, 2.1). Установщик в версию 1.0 не входит (SRS 3.5.1). Приложение не требует прав администратора (REQ-SEC-001), у проекта нет бюджета (SRS 3.5.7).

Вопрос: в каком виде поставлять приложение, чтобы его мог запустить пользователь без установленной среды .NET и без прав администратора?

## Драйверы решения

* Запуск без прав администратора и без предварительной установки .NET
* Простота сборки и публикации (SRS 3.5.2)
* Нулевая стоимость инструментов (SRS 3.5.7)
* Возможность добавить установщик позже без изменения кода (SRS 3.5.1)

## Рассмотренные варианты

* Переносимый архив self-contained для `win-x64`
* Переносимый архив framework-dependent
* Установщик (Inno Setup или MSIX)

## Итог решения

Выбранный вариант: «Переносимый архив self-contained для win-x64», потому что он запускается на чистой Windows 11 без установки .NET и без прав администратора и собирается одной командой `dotnet publish`.

### Последствия

* Хорошо, потому что пользователь распаковывает архив и запускает приложение.
* Хорошо, потому что воспроизводимая сборка и публикация в Releases.
* Хорошо, потому что установщик можно добавить позже, не меняя код.
* Плохо, потому что размер архива заметно больше из-за включённой среды выполнения (порядка десятков мегабайт).
* Плохо, потому что нет автообновления и пунктов в меню «Пуск».

### Подтверждение

Релизный чек-лист: запуск архива на чистой Windows 11 без установленного .NET и под обычной учётной записью. Сборка из исходников воспроизводится по инструкции в README (SRS 3.5.2).

## Плюсы и минусы вариантов

### Переносимый архив self-contained

* Хорошо, потому что не нужны права администратора и среда .NET.
* Хорошо, потому что простая сборка.
* Плохо, потому что больший размер.

### Переносимый архив framework-dependent

* Хорошо, потому что малый размер архива.
* Плохо, потому что требуется установленная среда .NET нужной версии, что ухудшает опыт «скачал и запустил».

### Установщик (Inno Setup или MSIX)

* Хорошо, потому что привычная установка и пункты меню «Пуск».
* Плохо, потому что дополнительная работа и инфраструктура; для MSIX нужна подпись пакета.
* Нейтрально, потому что отложено после версии 1.0 (SRS 3.5.1).

## Дополнительная информация

Связанные требования: SRS 3.5.1, 3.5.2, 3.5.7, REQ-SEC-001, REQ-COMP-001. Представление SDD: 012-deployment. Решение пересматривается при добавлении установщика после версии 1.0.
